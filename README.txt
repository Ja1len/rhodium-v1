RHODIUM ENGINEERING - GITHUB READY VERSION WITH EXTERNAL WEBSITE IMAGES

This version embeds product images directly by URL from the respective external website CDN links.
No local assets/images folder is required.

Deploy:
1. Extract ZIP.
2. Upload index.html plus catalogs, brochures, certifications folders to GitHub root.
3. Enable GitHub Pages from main branch / root.

Important:
Because the images are hot-linked from third-party websites, they depend on the original website/CDN staying online and allowing external display.
For final commercial deployment, replace them with your own licensed/approved product images.
